# Setup Instructions

## Prerequisites
- Node.js (v18+)
- npm (v9+)

## Installation
1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run start
   ```
   Navigate to `http://localhost:4200/`.

## Libraries used:
- Angular 17 (Standalone Components)
- Tailwind CSS
- Lucide Angular
- RxJS
